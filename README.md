# CREVIA MVP

Nuova base dell'MVP di Crevia.

## Vincoli tecnici
- Expo SDK 54
- React Native + TypeScript
- UI e identità visiva derivate dalla repository CREVIA originale
- Nessun redesign dell'app durante la migrazione MVP
- Backend progettato per Supabase, da collegare nella fase backend

## Core MVP
Project → Role → Application → Member → Completion → Verified Experience

La repository `CREVIA` originale resta separata e non viene modificata da questo progetto.
